Generated files live under `generated/` and are derived from YAML rules.

```bash
uv run lolpaths generate
```

Outputs:

- `generated/windows.txt`
- `generated/linux.txt`
- `generated/macos.txt`
- `docs/public/api/rules.json`
- `docs/public/api/stats.json`
- `docs/content/docs/<rule path>.mdx`

Platform files contain only paths for that platform. `docs/public/api/rules.json`
contains the complete normalized rule database.

The docs API and rule pages mirror the rule tree: source YAML produces public
API JSON and documentation content pages under matching category folders.

Do not edit generated files manually.
