title: Schema
description: The Pydantic contract for LOLPaths rules.
icon: Braces
---

The canonical structural schema is implemented as Pydantic models in:

```text
lolpaths/validator.py
```

It validates:

- Required fields
- Rule ID format
- Categories
- Sensitivity values
- Path kinds
- Platform arrays
- Metadata shape
- Content matcher structure

The validator also checks duplicate rule IDs and malformed content regexes.

Rule IDs use lowercase dot-separated identifiers:

```text
cloud.aws.credentials
ssh.private-keys
kubernetes.service-account-token
```
